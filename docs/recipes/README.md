# Recipes

Recipes are practical patterns that can be copied into real projects.

They should be smaller than full documentation and more concrete than methodology.

Good recipe topics:

- add a custom post type;
- add post meta exposed to REST;
- add a dynamic block;
- add an interactive block;
- add a block style variation;
- add a theme pattern;
- move an example into runtime code.

Recipes should name the files they affect and avoid introducing unnecessary architecture.
